# Contributing to roc-ansi

The contributor guide is the
[Contribute chapter](https://lukewilliamboswell.github.io/roc-ansi/contributing.html)
of the manual ([source](docs/contributing.adoc)). It covers what to install,
how to run the checks, and where each kind of test lives.

Use issues for bugs and design discussion, and pull requests for changes.
Before opening a pull request, run:

```sh
blueprint run check
```

Report a suspected vulnerability privately, as [SECURITY.md](SECURITY.md)
describes.
