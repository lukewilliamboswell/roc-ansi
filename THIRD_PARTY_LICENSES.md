# Unicode grapheme segmentation

The private `package/Unicode*.roc` modules adapt the grapheme-segmentation
subset of [roc-lang/unicode 4.3.1](https://github.com/roc-lang/unicode/tree/4.3.1/package).
The released source bundle has SHA-256
`119846d77be7e87cff22396219a8d060833c4ee2c3b7e54ba94dc2fb7a37d168`.
Private module names, duplicate local names and the iterator length argument
are adapted for the November 18 Roc compiler. The segmentation rules and
Unicode 17.0.0 property data are unchanged.
