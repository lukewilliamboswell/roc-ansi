Getting started

app [main!] {
	ansi: "https://github.com/lukewilliamboswell/roc-ansi/releases/download/0.12.0/J75zfZxPJQwSG7sQJFnZHVAbJj55L3myvst2WcDWcEaZ.tar.zst",
}

import ansi.ANSI
import ansi.C16
import ansi.Color

main! = |_args| {
	greeting = ANSI.color("hello", { fg: Color.Color.Standard(C16.Name.Green), bg: Color.Color.Default })
	echo!(greeting)
	Ok({})
}

Add the ansi dependency to your app header, then import the modules you need. Every release publishes a bundled package URL.
