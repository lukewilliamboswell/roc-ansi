Small, composable building blocks

Style text

Apply 16-color, 256-color, or RGB foreground and background colors alongside bold, italic, underline, and other styles.

Control the terminal

Move the cursor, erase regions, scroll, query terminal state, and render screen-oriented layouts.

Handle input

Parse raw terminal bytes into typed keys, arrows, controls, symbols, and cursor positions.

A quick taste

app [main!] {
	ansi: "https://github.com/lukewilliamboswell/roc-ansi/releases/download/0.12.0/J75zfZxPJQwSG7sQJFnZHVAbJj55L3myvst2WcDWcEaZ.tar.zst",
}

import ansi.ANSI
import ansi.C16
import ansi.Color

main! = |_args| {
	greeting = ANSI.color("hello", { fg: Color.Color.Standard(C16.Name.Green), bg: Color.Color.Default })
	echo!(greeting)
	Ok({})
}

Add the ansi dependency to your app header, then import the modules you need. Each release publishes the bundled package to depend on.
