= roc-ansi 0.13.3

This patch changes no package APIs or example output. It upgrades the release
examples archive to the canonical roc-automation compatibility suite format.
The suite declares its release and immutable dependencies, and records explicit
arguments, input, standard output, standard error and exit status for every case.

== Use this release

[source,roc]
----
app [main!] {
    ansi: "{package-url}",
}
----

== Tooling and documentation

* Blueprint 0.7.0 provides the development environment without Nix.
* roc-automation tools-0.3.0 renders the manual as HTML, PDF and Markdown,
  replacing the Asciidoctor Docker image.
* CI reports renderer provisioning, rendering, preparation and API reference
  timings separately, with renderer memory and output sizes.
* The shared nightly compatibility runner retains successful compiler diagnostics.

== Supply-chain evidence

* The source bundle gains SPDX and CycloneDX sidecars bound to its final SHA-256,
  plus retained signed provenance and SBOM-attestation evidence.
* Every source module carries its copyright and UPL-1.0 notice.
* The source inventory has no external package dependencies. Compiler/toolchain
  closure remains an explicit coverage gap; examples and documentation are
  separate deliverables.
