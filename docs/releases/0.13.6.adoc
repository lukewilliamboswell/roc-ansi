= roc-ansi 0.13.6

The five published examples use basic-cli 0.28.1 and work with Roc nightly
`nightly-2026-11-18-a520eed`. This fixes the entrypoint type errors reported
by this compiler with basic-cli 0.27.0. Package APIs and example output are
unchanged.

== Use this release

[source,roc]
----
app [main!] {
    ansi: "{package-url}",
}
----
