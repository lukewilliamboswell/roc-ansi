# Security policy

## Supported versions

Security fixes are made on `main` and included in the next release. Only the
latest release and `main` are supported.

## Report a vulnerability privately

Do not report a suspected vulnerability in a public issue, discussion or pull
request. Use
[GitHub private vulnerability reporting](https://github.com/lukewilliamboswell/roc-ansi/security/advisories/new),
so the details stay private while they are investigated.

Include the affected version or commit, the impact, steps or a minimal program
that reproduces the problem, and any mitigation you know of.
